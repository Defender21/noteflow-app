# NoteFlow Pro — Менеджер нотаток із категоріями та пошуком

Проєкт розроблено в межах навчальної практики з програмування (Частина 3)  
здобувачем освіти 3 курсу групи КН-33 Щербаком Тимофієм Ігоровичем.

##  Основний функціонал
- Створення, редагування, видалення та закріплення нотаток (CRUD);
- Фільтрація нотаток за категоріями та мультитегами;
- Живий повнотекстовий пошук за заголовком, текстом та тегами;
- Клієнтський Dependency Injection (DI) контейнер для інкапсуляції сервісів;
- Браузерне LocalStorage API для автозбереження чернеток форми введення;
- Серверний REST API на базі Node.js/Express із вбудованою Swagger UI специфікацією.

## 🛠 Технологічний стек
- **Front-end:** React 18, Vite, SCSS (БЕМ, змінні, міксини), Dependency Injection (DI Container), Browser Storage API (LocalStorage), Lucide React.
- **Back-end:** Node.js, Express, CORS, Swagger UI Express.
